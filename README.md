# 🐍 Atividades Práticas — Análise de Dados com Python

Conjunto de **11 atividades práticas** para Google Colab, cada uma com notebook do **ALUNO** (com espaços `# ✏️ SEU CÓDIGO AQUI`) e do **GABARITO** (solucionado e validado).

## Como usar

1. Acesse [Google Colab](https://colab.research.google.com).
2. `Arquivo > Fazer upload do notebook` → escolha o `.ipynb` desejado.
3. Execute com `Shift + Enter` e complete as tarefas.

> Os notebooks do exercício 3 e 11 dependem de arquivos extras (`.csv` / `.py`) que estão na mesma pasta.
